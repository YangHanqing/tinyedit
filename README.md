# TinyEdit 极简编辑器

**简体中文** | [English](README.en.md)

TinyEdit 是一款面向 **macOS** 的原生文本编辑器，专注于 TXT、Markdown（MD）、JSON 等常见文本文件的日常阅读与编辑。采用 SwiftUI 构建简洁、现代的界面，在保持轻巧的同时，提供日常所需的完整编辑功能。

TinyEdit 不做项目管理等 IDE 功能，侧边栏只用来浏览文件夹。打开文件即可阅读和修改，也可以直接输入内容，无需先新建文件。标签页和未保存的内容会自动保留，关闭窗口或退出应用后，再次打开即可继续编辑。

### 通用功能

| 功能名称 | 介绍 | 图片 |
| --- | --- | --- |
| 日常编辑 | 多标签页、查找替换、自动换行、行号、缩进参考线、括号配对和选中词高亮。支持按行复制、移动、删除、合并及切换注释。还可以比较两个标签页，或比较标签页与磁盘上的文件（右键标签页 ▸ 比较对象）。 |  |
| 文件与编码 | 支持 UTF-8、UTF-16、GB18030（兼容 GBK / GB2312），保留换行格式。文件被其他应用修改或删除时会提示，重新加载后标出变化的行。 |  |
| 文件夹与窗口 | 打开或拖入一个文件夹，会在新窗口中打开，左侧边栏列出其中的文件，点击即可打开；磁盘上的变化会自动刷新。项目窗口的侧栏按钮位于标题栏右侧，普通文件窗口不显示。拖动侧栏右边缘可调整宽度，深层目录支持横向滚动。文件夹移动或改名后会跟随更新，删除后保留已打开的文本。⇧⌘N 新建窗口，⌃⌘S 显示或隐藏边栏。把标签页拖出窗口即成为新窗口，拖到另一个窗口则移过去。每个窗口的标签页、文件夹和位置在重新打开后都会恢复。 |  |
| 命令行 | 在终端里运行 `tinyedit 文件` 打开文件，`tinyedit 文件:120` 打开并跳到第 120 行，`命令 \| tinyedit` 把命令的输出放进新标签页。安装方法见下方[命令行](#命令行)。 |  |
| 自动恢复 | 自动保留标签页、未保存文本、光标和滚动位置。恢复内容与原文件分开存储，只有主动保存时才修改原文件。 |  |
| 图片文字识别 | 粘贴截图或拖入图片，即可将识别出的文字插入编辑区。使用 Apple Vision 在本机处理；macOS 26 上还可将表格识别为便于粘贴到表格软件的文本。 |  |
| 外观与语言 | 支持浅色、深色和跟随系统，提供记事本、代码编辑器、文稿、极简光标四款应用图标及多种编辑区背景。界面支持简体中文、繁体中文、英语、日语、韩语、德语、法语和西班牙语。 |  |
| 语法高亮 | 支持 JSON、Markdown、Python、JavaScript、TypeScript、Swift、SQL、YAML 等 36 种语言和格式，可根据文件和内容自动识别，也可通过底部栏手动切换。 | <img src="assets/screenshots/syntax-highlighting.png" alt="语法高亮" width="560"> |
| 命令面板 | 按 ⇧⌘P 搜索并执行命令，也可以查找已打开的标签页。支持以下操作：<br>• JSON：格式化、压缩、字符串转义与还原。<br>• 编码转换：Base64/URL 编解码、Unicode 转义还原、JWT 解码、Unix 时间戳转日期。<br>• 行处理：升序/降序排序、反转行顺序、随机打乱、移除重复行。<br>• 文本清理：移除空行、行尾空白、ANSI 转义码（终端颜色等）和不可见字符。<br>• 翻译与请求：翻译选中文字或整篇文档、发送 curl 请求。<br>文本工具优先处理选区，未选中时处理整篇文档；文本修改可以撤销。 | <img src="assets/screenshots/command-palette.png" alt="命令面板" width="560"> |
| 随手计算 | 在文本中输入算式，行尾便会提示结果，按 Tab 即可插入。支持四则运算、括号、乘方 `2^10`、开方 `sqrt(144)`、百分比、取余、阶乘、`max`/`min`/`avg`、取整、对数和三角函数，也支持全角符号。能精确计算时使用十进制，`0.1 + 0.2` 可得到 `0.3`。默认在纯文本中启用，也可扩展到 Markdown。 | <img src="assets/screenshots/calculator.png" alt="随手计算" width="560"> |
| curl 请求 | 粘贴 curl 命令后，可先查看请求信息，再点击 Send 直接发送。响应卡片显示状态码、耗时、大小、正文和响应头，JSON 正文会自动格式化；结果可以复制、替换原命令或在新标签页打开。无需启动终端，发送前不会发起请求。 | <img src="assets/screenshots/curl-request.png" alt="curl 请求与响应" width="560"> |
| 翻译 | 翻译选中文字或整篇文档，原文与译文并排显示。译文可以复制、替换原文或在新标签页打开。支持 Apple 系统翻译，以及兼容 OpenAI 接口的云端服务和本地模型；长文本分段处理，中断后可继续。 | <img src="assets/screenshots/translation.png" alt="文本翻译" width="560"> |
| 自动识别粘贴内容 | 以 Base64 为例，粘贴后即可查看解码结果，并选择复制或替换。还支持 JWT、URL 编码、Unicode 转义、JSON 字符串和 Unix 时间戳。粘贴内容含终端颜色代码或不可见字符时，也会提示清理。 | <img src="assets/screenshots/paste-base64.png" alt="自动识别并解码粘贴的 Base64 内容" width="560"> |

## 下载与安装

在 [Releases](../../releases) 页面下载最新版本，将 TinyEdit 拖入“应用程序”文件夹。

- macOS 15 或更高版本。
- Apple 芯片（M 系列）或 Intel Mac。
- 单个文件最大 64 MB；超过 2 MB 时仅高亮可见区域，超过 5 MB 时关闭语法高亮与 Markdown 预览。

## 命令行

TinyEdit 自带 `tinyedit` 命令。在 设置 ▸ 通用 ▸ 命令行工具 中点击“拷贝”，将安装命令粘贴到“终端”中运行（需要输入管理员密码）。命令会链接到应用内的脚本，TinyEdit 更新后无需重新安装。

```sh
tinyedit notes.md             # 打开文件；文件不存在时先创建空文件
tinyedit a.txt b.json         # 一次打开多个文件，每个文件一个标签页
tinyedit .                    # 在新窗口中打开当前文件夹
tinyedit main.swift:120       # 打开并跳到第 120 行（main.swift:120:5 同时指定列）
curl -s https://api.example.com/items | tinyedit   # 将命令的输出放进新的未命名标签页
pbpaste | tinyedit            # 管道输入同样会提示语言、格式化 JSON、清理终端颜色代码
tinyedit                      # 将 TinyEdit 切换到前台
tinyedit -h                   # 查看全部用法
```

## 隐私与联网

TinyEdit 不收集用户数据。文本编辑、图片文字识别、文本工具和内容恢复均在本机完成。Apple 系统翻译在本机运行，首次使用某种语言时可能需要下载语言包。

## 从源码构建

安装 Xcode 27 或更高版本及 XcodeGen，在仓库根目录运行 `xcodegen generate`，然后打开 `TinyEdit.xcodeproj`，选择 **TinyEdit** scheme 运行。
